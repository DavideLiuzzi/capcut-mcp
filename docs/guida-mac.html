Come leggere questa guida

Le voci dei menu sono scritte così: Impostazioni (Settings) → Estensioni (Extensions). Tra parentesi trovi il nome inglese, perché l'app può essere in italiano o in inglese e le etichette possono cambiare leggermente da una versione all'altra.

I tasti del Mac: ⌘ è il tasto Cmd (Command), ⇧ è Maiusc. Per esempio ⌘Q vuol dire: tieni premuto Cmd e premi Q.

I riquadri PROMPT contengono frasi da copiare e incollare nella chat di Claude: sostituisci solo i nomi tra virgolette con quelli delle tue bozze.

Prima di iniziare controlla di avere tutto. L'installazione completa richiede circa 30–40 minuti, la maggior parte per gli scaricamenti automatici (Homebrew, ffmpeg e il modello di trascrizione).

Hai scaricato i file con Safari?

Safari a volte estrae gli zip da solo: se al posto di capcut-reels-skill.zip trovi una cartella, apri Safari → Impostazioni → Generali, togli la spunta a Apri i documenti “sicuri” dopo il download e scarica di nuovo lo zip.

Estensione e skill: che differenza c'è?

L'estensione sono le “mani”: senza di lei Claude non può toccare i file di CapCut. La skill è il “mestiere”: senza di lei Claude ha gli strumenti ma lavora in modo meno preciso (per esempio potrebbe scegliere lui la presa migliore invece di tenerle tutte). Installa sempre entrambe.

Cosa fa (e cosa non fa)

SA FARE
  • Premontaggio dei girati parlati: toglie silenzi e frasi interrotte, tiene tutte le prese complete
  • Trascrizione offline sul Mac (Whisper)
  • Aggiungere, spostare, tagliare, dividere clip, immagini, audio e testi
  • Sottotitoli con lo stile di un testo che hai già
  • Copiare transizioni, animazioni ed effetti già usati
  • Inserire grafiche e b-roll generati altrove (es. Higgsfield)
  • Backup automatico a ogni salvataggio
NON FA
  • Non esporta il video finale: l'esportazione si fa in CapCut
  • Non inventa effetti o transizioni di CapCut: può solo copiare quelli già usati in una bozza
  • Non lavora mentre CapCut è aperto
  • Non funziona dal sito web claude.ai né dal telefono: serve l'app desktop sul Mac dove ci sono le bozze
1

Installare Claude Desktop e collegare l'account

Claude Desktop è l'app di Claude per il computer. È l'unica versione che può usare le estensioni installate sul Mac, quindi è indispensabile.

1.1 Scaricare l'app

  1. Apri il browser e vai su claude.ai/downloadÈ la pagina ufficiale. Scarica solo da qui, non da siti di terze parti.
  2. Scegli la versione per macOSViene scaricato un file .dmg, di solito nella cartella Download.

1.2 Installare

  1. Fai doppio clic sul file .dmg scaricatoSi apre una finestra con l'icona di Claude e la cartella Applicazioni.
  2. Trascina l'icona di Claude sulla cartella ApplicazioniAttendi la fine della copia. Poi puoi chiudere la finestra ed espellere il disco “Claude” dalla barra laterale del Finder.
  3. Apri ClaudeDa Applicazioni, oppure con Spotlight: premi ⌘ Spazio, scrivi Claude e premi Invio. Se macOS chiede «“Claude” è un'app scaricata da Internet. Vuoi aprirla?», clicca Apri.
  4. Tienila nel Dock (consigliato)Con Claude aperto: clic destro sulla sua icona nel Dock → Opzioni → Mantieni nel Dock.

1.3 Accedere con il tuo account

  1. Alla prima apertura scegli come accederePuoi usare Continua con Google oppure inserire il tuo indirizzo email.
  2. Se hai scelto l'email, controlla la postaTi arriva un codice o un link di accesso: inseriscilo o cliccalo. Se l'account non esiste ancora, viene creato in questo passaggio.
  3. Completa i dati richiestiNome, conferma dell'età e accettazione dei termini di servizio.
  4. Scegli il pianoPuoi partire con il piano gratuito e passare a un piano a pagamento in seguito da Impostazioni (Settings) → Abbonamento (Billing).
Quale piano?

Il montaggio con Claude usa molti messaggi: ogni bozza letta, ogni trascrizione e soprattutto ogni fotogramma mostrato a Claude consuma il limite di utilizzo. Con il piano gratuito il limite si raggiunge in fretta. Per lavorare su più video al giorno è consigliato almeno Pro; per uso intensivo Max. Verifica prezzi e limiti aggiornati sulla pagina dei piani di Claude.

Usare lo stesso account su più computer

Puoi accedere con lo stesso account su più computer, Mac o Windows. La skill si carica una volta sola e la ritrovi ovunque; l'estensione invece va installata su ogni computer dove ci sono le bozze di CapCut, perché lavora sui file locali.

Collegare l'estensione CapCut (MCP)

L'estensione “CapCut – montaggio bozze” è il server MCP che collega Claude alle bozze di CapCut. Si installa con un doppio clic.

2.1 Installare il file .mcpb

  1. Con Claude Desktop aperto, fai doppio clic su capcut-mcp.mcpbClaude Desktop si porta in primo piano e mostra la scheda dell'estensione “CapCut – montaggio bozze” con descrizione ed elenco degli strumenti.
  2. Clicca su Installa (Install)Se compare un avviso sull'origine dell'estensione, conferma: è normale per le estensioni che non vengono dalla directory ufficiale.
  3. Compila le impostazioni (puoi lasciarle vuote) e verifica che sia Attiva (Enabled)Vedi la tabella qui sotto. Nella maggior parte dei casi basta confermare senza scrivere nulla.
Se il doppio clic non funziona

Fai clic destro sul file → Apri con → Claude. Oppure in Claude apri Impostazioni (Settings, ⌘,) → Estensioni (Extensions) → Impostazioni avanzate (Advanced settings) → Installa estensione (Install Extension) e scegli il file capcut-mcp.mcpb.

Importare la skill capcut-reels

La skill è un pacchetto di istruzioni: insegna a Claude come fare un premontaggio, come riconoscere le frasi dettate da dietro la camera, come mettere sottotitoli e grafiche. Si attiva da sola quando parli di CapCut, bozze, premontaggio o reel.

3.1 Caricare lo zip

  1. Apri Personalizza (Customize) → SkillsLo trovi nel menu laterale di Claude Desktop (o tramite le Impostazioni).
  2. Clicca su Carica skill (Upload skill)Di solito è un pulsante “+” o “Carica”.
  3. Scegli il file capcut-reels-skill.zipNon estrarlo: va caricato lo zip così com'è.
  4. Attiva l'interruttore accanto a capcut-reelsLa skill compare nell'elenco con la sua descrizione.
Non vedi la sezione Skills?

Le skill richiedono che sia attiva l'esecuzione del codice. Vai in Impostazioni (Settings) → Funzionalità (Capabilities) e attiva Esecuzione di codice e creazione di file (Code execution and file creation), poi riprova. Se ancora non compare, aggiorna Claude Desktop all'ultima versione (menu Claude → Verifica aggiornamenti).

3.2 Verificare che la skill venga usata

Non serve richiamarla a mano: quando scrivi per esempio «fai il premontaggio della bozza…», Claude la carica da solo (nella chat vedi un passaggio tipo “lettura skill capcut-reels”). Se vuoi essere sicuro, aggiungi al prompt: «usa la skill capcut-reels».

3.3 Facoltativo: collegare Higgsfield

Se vuoi che Claude generi grafiche animate, motion o b-roll e li metta direttamente nella bozza, collega anche il connettore di Higgsfield da Impostazioni → Connettori (Connectors) e accedi con il tuo account Higgsfield. Senza connettore puoi comunque incollare in chat il link di un file generato: Claude lo scarica e lo inserisce.

Primo avvio: Homebrew e il setup

La trascrizione funziona offline sul tuo Mac, quindi servono due componenti: ffmpeg (il programma che legge video e audio, nella versione completa con Whisper) e il modello Whisper (~600 MB). Sul Mac ffmpeg si installa con Homebrew, il programma di installazione più usato su Mac: lo installi tu una volta sola, poi Claude fa il resto.

4.1 Installare Homebrew (una volta sola)

  1. Apri il TerminalePremi ⌘ Spazio, scrivi Terminale e premi Invio. Si apre una finestra in cui si scrivono comandi.
  2. Copia il comando di installazione da brew.shÈ il sito ufficiale di Homebrew: sotto “Install Homebrew” c'è il comando con il pulsante per copiarlo. Al momento è questo: 
    /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
  3. Incolla il comando nel Terminale (⌘V) e premi InvioQuando chiede Password, scrivi la password del Mac e premi Invio: mentre scrivi non compare nulla, è normale. Quando chiede Press RETURN/ENTER to continue, premi Invio.
  4. AttendiRichiede 5–15 minuti. Può scaricare anche gli “Strumenti da riga di comando di Xcode” (Command Line Tools): è normale.
  5. Alla fine compare “Installation successful!”Le istruzioni “Next steps” che seguono non servono per CapCut: puoi chiudere il Terminale.
  6. Esci da Claude con ⌘Q e riapriloCosì l'estensione vede Homebrew.

4.2 Il setup in Claude

  1. Apri una nuova chat e scrivi:
    Esegui capcut_setup con install true.
  2. Autorizza lo strumentoClaude Desktop ti chiede il permesso di usare capcut_setup: clicca Consenti (Allow).
  3. AttendiIl setup gira in background: installa ffmpeg-full con Homebrew (circa 1–2 GB) e scarica il modello in ~/Library/Application Support/capcut-mcp/models. Richiede 10–30 minuti, a seconda della connessione.
  4. Chiedi a che punto è
    A che punto è il setup?
  5. Verifica che sia tutto pronto
    Esegui capcut_setup senza installare e dimmi se è tutto pronto.
    Deve risultare pronto: ffmpeg, filtro whisper, modello e cartella delle bozze trovati.
Se qualcosa va storto
  • “Homebrew non è installato”: ripeti il punto 4.1. Se l'hai appena installato, esci da Claude con ⌘Q, riaprilo e riprova.
  • “Mac con processore Intel” o “serve macOS 15 Sequoia”: su quel Mac l'installazione automatica non è disponibile. Se il Mac ha il chip Apple, aggiorna macOS da Impostazioni di Sistema → Generali → Aggiornamento software.
  • “ffmpeg installato ma non trovato”: esci da Claude con ⌘Q, riaprilo e ripeti il controllo.
  • Il setup si ferma con un errore di Homebrew: puoi installare ffmpeg a mano nel Terminale con brew install ffmpeg-full, poi ripeti il controllo in Claude.

4.3 I permessi di macOS

La prima volta che Claude apre cartelle come Scrivania, Documenti o Download, macOS chiede: «“Claude” vorrebbe accedere ai file nella cartella …». Clicca Consenti: senza permesso Claude non vede i tuoi video. Se hai cliccato “Non consentire” per sbaglio: Impostazioni di Sistema → Privacy e sicurezza → File e cartelle → Claude e attiva la cartella.

4.4 I permessi degli strumenti

Come per capcut_setup, ogni volta che Claude usa uno strumento nuovo Claude Desktop chiede il permesso. Puoi scegliere Consenti una volta o Consenti sempre.

  • Consenti sempre va bene per gli strumenti di sola lettura (elenco bozze, lettura timeline, fotogrammi, trascrizione) e per quelli di modifica in memoria.
  • Per capcut_save, capcut_restore_backup, capcut_ffmpeg e capcut_raw_patch puoi preferire Consenti una volta: così vedi ogni volta quando Claude scrive sul disco.

5.2 Concetti da sapere

BozzaUn progetto di CapCut. Claude lo riconosce dal nome che vedi nella schermata iniziale di CapCut: scrivilo esattamente uguale, tra virgolette.
Modifiche in memoriaTutto quello che Claude fa (aggiungere, tagliare, spostare…) resta in sospeso finché non chiedi di salvare. Puoi chiedere di annullare in qualsiasi momento.
SalvataggioScrive la bozza su disco. Funziona solo con CapCut chiuso (⌘Q, non basta chiudere la finestra). Prima di scrivere fa sempre un backup.
BackupUna copia della bozza prima di ogni salvataggio (vengono tenute le ultime 25). Si ripristina con una frase: «ripristina l'ultimo backup della bozza…».
Traccia principaleLa prima traccia video, quella del girato. Il premontaggio lavora solo su questa.
PresaUna ripetizione completa di una frase. Di default vengono tenute tutte: scegli tu quale usare.
TempiIn secondi (es. “al secondo 12”) o minuti:secondi (es. “a 1:05”).

5.3 Cosa succede durante un premontaggio

  1. Claude legge la bozzae trova i file del girato sulla traccia principale.
  2. Trascrive ogni fileoffline: ottiene i “blocchi” di parlato con inizio, fine, volume e testo. Servono alcuni secondi per frase: su un girato lungo può volerci qualche minuto. Se Claude dice che manca molto, fai altro e poi scrivigli «continua» o «a che punto sei?».
  3. Decide cosa tenereTiene tutte le prese complete; toglie silenzi, frasi lasciate a metà, rumori, commenti fuori copione e le frasi dettate da dietro la camera (che verifica guardando i fotogrammi).
  4. Ricostruisce la traccia principaleUna presa dopo l'altra, in ordine cronologico, ognuna come clip separato.
  5. Controlla, ti chiede di uscire da CapCut e salva
  6. Ti fa un riepilogoDurata prima/dopo, tabella con tempo, frase e numero di prese, prese dubbie e frasi dettate tolte.

I prompt da dare

Frasi pronte da copiare. Sostituisci i nomi tra virgolette con quelli delle tue bozze e dei tuoi file.

Come scrivere un buon prompt
  • Nomina sempre la bozza, tra virgolette, esattamente come in CapCut.
  • Dì cosa tenere e cosa togliere, non solo “sistemalo”.
  • Chiedi prima un piano per le modifiche grandi: «prima dimmi cosa intendi fare, non salvare».
  • Una cosa alla volta: premontaggio, poi sottotitoli, poi grafiche. Più facile da controllare.
  • Per le prove usa una copia della bozza.
  • Una chat per progetto: le chat lunghe diventano lente e consumano il limite più in fretta.

Le accortezze

Poche regole che evitano il 90% dei problemi.

!
Esci da CapCut prima di salvare, con ⌘QSul Mac chiudere la finestra non basta: CapCut resta aperto (lo vedi dal puntino sotto la sua icona nel Dock). Usa ⌘Q oppure il menu CapCut → Esci da CapCut. CapCut salva in automatico a intervalli: se è aperto mentre Claude salva, sovrascrive le modifiche. Claude rifiuta di salvare se CapCut è aperto: non chiedergli di “forzare” a meno che tu sia sicuro che sia chiuso.
!
Non spostare né rinominare i file del giratoLa bozza punta ai file originali. Se li sposti, CapCut li mostra come mancanti. Tieni il girato in una cartella fissa prima di iniziare: meglio dentro Filmati o in una cartella dedicata che sulla Scrivania o in Download, perché macOS protegge quelle cartelle e CapCut potrebbe chiederti di ricollegare i file.
!
Dopo ogni salvataggio, riapri e controllaIl formato delle bozze di CapCut non è documentato. Dopo modifiche grandi apri la bozza e guardala dall'inizio alla fine prima di esportare.
!
La prima volta lavora su una copiaChiedi a Claude di duplicare la bozza e lavora sulla copia finché non prendi confidenza. La versione per Mac è nuova: vale doppio. In ogni caso i backup permettono di tornare indietro.

A.2 Dove sono i file

Backup delle bozze~/Library/Application Support/capcut-mcp/backups/<bozza>/<data-ora> — ultime 25 per bozza
Modelli di trascrizione~/Library/Application Support/capcut-mcp/models
File scaricati~/Movies/CapCut MCP — nel Finder è Filmati (o la cartella scelta nelle impostazioni)
Bozze di CapCut~/Movies/CapCut/User Data/Projects/com.lveditor.draft (posizione standard)

Per aprire una di queste cartelle: nel Finder scegli Vai → Vai alla cartella… (⇧⌘G), incolla il percorso e premi Invio. Il simbolo ~ indica la tua cartella Inizio; Library nel Finder si chiama Libreria.

A.3 Aggiornare a una nuova versione

Quando ricevi un nuovo capcut-mcp.mcpb, fai doppio clic: sostituisce la versione installata. Se dovesse comparire due volte, disinstalla la vecchia da Impostazioni → Estensioni. Backup e modello Whisper restano dove sono, non vanno riscaricati. Se ricevi anche un nuovo capcut-reels-skill.zip, elimina la skill vecchia in Personalizza → Skills e carica quella nuova. Per aggiornare ffmpeg (facoltativo), nel Terminale: brew upgrade ffmpeg-full.

A.4 Installazione manuale (utenti esperti)

In alternativa al file .mcpb, il server si può registrare a mano. Serve Node.js 18+ e una copia del codice:

  1. Scarica il codice e le dipendenzegit clone https://github.com/DavideLiuzzi/capcut-mcp, poi nella cartella npm install.
  2. In Claude DesktopApri Impostazioni → Sviluppatore (Developer) → Modifica configurazione e aggiungi in mcpServers la voce "capcut" con "command": "node" e "args" con il percorso assoluto di src/server.js.
  3. In alternativa, in Claude Codeclaude mcp add capcut --scope user -- node "/Users/nome/capcut-mcp/src/server.js"
  4. RiavviaEsci da Claude con ⌘Q, riaprilo e carica la skill come nel capitolo 3.
